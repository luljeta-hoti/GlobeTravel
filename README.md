# 🌍 GlobeTravel — Travel Agency Website

GlobeTravel is a travel agency website developed as a course project using HTML and CSS. It was designed to present a fictional travel agency's services, travel packages, company information, and team through a structured and visually engaging interface.

The website combines travel-focused imagery, a blue and white colour palette, clear content organization, and card-based layouts to create a consistent visual experience.

## 🎯 Project Goal

The goal of this project was to design and develop a complete travel agency website that presents travel services and packages in an attractive and accessible way. It focuses on organizing information clearly and providing visitors with an intuitive way to explore the agency and its offerings.

## ✨ Key Features

- **Hero Section** — Introductory content with travel imagery and a call-to-action.
- **Navigation** — Links to the main sections of the website.
- **About Us** — Information about the agency and its approach to travel.
- **Company Statistics** — Achievements and customer satisfaction information.
- **Travel Services** — Services displayed through structured cards.
- **Booking Process** — A step-by-step overview of the travel booking journey.
- **Team Section** — Presentation of agency members and their roles.
- **Travel Packages** — Package descriptions, pricing, and included features.
- **FAQ Section** — Answers to common customer questions.
- **Contact Section** — Contact and consultation information.
- **Footer** — Company details, navigation links, and social media elements.

## 🎨 Design & Development

The website uses a blue and white colour palette, travel-related imagery, Poppins typography, custom icons, rounded interface elements, and card-based layouts.

The interface was developed using:

- **HTML5** for page structure and content.
- **CSS3** for styling, layouts, and visual presentation.
- **CSS Flexbox and Grid** for arranging page elements.
- **CSS Variables** for consistent styling.
- **Google Fonts (Poppins)** for typography.

The design focuses on visual consistency, clear information hierarchy, and an organized presentation of content.
